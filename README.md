# Employee Management System - Java Full Stack 💚

A complete CRUD web application built from scratch in 12 Days Challenge!

### 🚀 Live Features (100% Working)
✅ Add Employee - CREATE
✅ View All Employees - READ  
✅ Edit Employee - UPDATE
✅ Delete Employee - DELETE

### 🛠️ Tech Stack Used
- Java, Jakarta Servlets, JSP, JSTL
- MySQL Database + JDBC
- Apache Tomcat 10
- HTML, CSS
- Git & GitHub

### 📸 Screenshots
- Employee List with Blue Edit & Red Delete Buttons
- Add Employee Form (Green Card)
- Edit Employee Form (Blue Card)

### ▶️ How to Run
1. Clone this repo
2. Create DB `employee_db` and table `employees(id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(100), email VARCHAR(100), salary DOUBLE)`
3. Update DBConnection.java with your MySQL password
4. Run on Tomcat 10 -> http://localhost:8080/employees
